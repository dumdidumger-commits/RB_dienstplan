# RB Add-ons

Home-Assistant-Add-on-Repository mit zwei eigenständigen Add-ons:

- **[dienstplan_sync](dienstplan_sync/README.md)** — synchronisiert den Vivendi-Dienstplan
  täglich mit Google Calendar. Produktiv seit 30.07.2026.
- **[zenwave_sync](zenwave_sync/README.md)** — liest Verbrauch/Preis/Kosten aus dem
  ZenWave-Kundenportal (Zendure) aus. Erster Entwurf seit 09.08.2026, noch nicht gegen die
  echte Seite getestet.

Repository ursprünglich mit nur einem Add-on direkt im Root angelegt, am 09.08.2026 in die
Unterordner-Struktur umgebaut, um ein zweites Add-on aufzunehmen.
